# Risk-Decoupled Adaptive Trajectory Planning for UAVs

This repository accompanies *A risk-decoupled adaptive trajectory planning method for UAVs in constricting narrow passages* by Tianyu Shi and Huifeng Tian. It contains the ROS 2 implementation, simulation data, and scripts for reproducing the manuscript's figures and tables.

- [Reproduction guide](data/README.md) — environment setup, experiment data, and figure and table reproduction.
- [Core implementation](data/src/README.md) — algorithm architecture and ROS 2 build and launch instructions.
